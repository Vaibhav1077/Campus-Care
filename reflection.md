# Reflection – CampusCare

For this assignment, I built CampusCare — a hostel maintenance complaint management system. The idea came from a simple problem: in most college hostels, students have no proper way to report a maintenance issue. They either call the warden directly, send a WhatsApp message, or just wait and hope someone notices. There is no tracking, no priority, and no record of what was fixed and when. I wanted to build something that made this process more organised for both students and maintenance staff.

The application has two separate portals — one for students and one for admins. Students can log in, submit a complaint with their hostel block, room number, category and description, and then track its status. Admins can view all complaints, filter them, assign staff, update statuses, and see a dashboard with complaint statistics. The system also has a priority engine that automatically classifies complaints based on the type of issue — for example, an electrical spark is marked Critical, while a cleaning request gets a lower priority. I built this using Python, Streamlit, and pandas, with data stored in a CSV file.

The biggest challenge I faced was the UI. Streamlit's default interface looks very plain, and making it look professional required writing a lot of custom CSS. Getting the sidebar, cards, and metric boxes to override Streamlit's built-in styles took more time than I expected. Another challenge was making the priority engine work correctly — I had to make sure it was actually called during complaint submission rather than just assigning "Medium" to everything by default, which was what the code was doing initially.

One thing I would improve with more time is replacing the CSV storage with a proper database like SQLite. The current CSV approach works for a small number of records, but it is not suitable for a real hostel with hundreds of complaints. I would also add real authentication with password hashing rather than the simple demo login that currently exists. Email notifications when a complaint status changes would also be a useful addition.

Overall, building CampusCare was a good learning experience. I got better at structuring a multi-page Streamlit application, understanding role-based access in a simple system, and thinking about data validation and CSV schema design. The project also made me think about a real problem that exists in college hostels and how even a basic digital tool can make a noticeable difference to how complaints are handled.
